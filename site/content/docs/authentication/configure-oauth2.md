Configure ZAP to use OAuth2.0 for your APIs.

The OAuth2.0 authentication method is provided by the Authentication Helper add-on. Configure the token endpoint, grant type, client credentials and client authentication method, then link the authentication to your verification rules.

For full details see the [OAuth2.0 authentication documentation](/docs/desktop/addons/authentication-helper/oauth2-auth/).
